Giant Knelt build: run order notes (written 11-13 by the NEW STORY thread for the Part 3 thread)

How it ran: two persistent Blender (bpy) servers, each polling a command folder.
  gsrv.py  -> loads set_gk.py (town square set, based on sky/set_sky.py + sky/look3.py + oc/base.py), reads gk/cmd/
  lsrv.py  -> loads set_land_gk.py (the land / mountain / castle set), reads gk/lcmd/
send.py / lsend.py write a command file into cmd/ or lcmd/ from a file in cmd_src/ (or inline text); tr.sh / ltr.sh / ptr.sh are the
test-render wrappers (ptr.sh = Part 2 shots, scenes_p2.py); dry.sh / ldry.sh / pdry.sh = camera-only dry runs.
The cmd_src files are PATCHES applied to a running server after the set loaded (knight_v2.py, rebuild_knight.py, titan*.py,
mountain2.py, p2props.py, gk_props.py, court_floor.py, poster_fix.py, steel_rough.py, trim_rough.py, palm_mat.py ...).
run.py / run_l.py / run_p2.py are the shot runners (exec scenes_gk.py / scenes_land.py / scenes_p2.py and render WANT).
The lists below are the real command files as they ran, oldest first (repeats of the same name collapsed). The copies of every
command file as sent are in gk/cmd/ and gk/lcmd/ in this tar, so the exact text of each step is there.
I have not re-verified a clean rebuild from zero; if a patch fails, read the matching file in cmd/ or lcmd/ (it is the truth).
Part 2 end state (titan kneeling, queen without crown, rabbit, castle on the mountain) is posed per shot inside scenes_p2.py;
the props it needs come from p2props.py (sent before the first Part 2 render) on top of the Part 1 patches.
